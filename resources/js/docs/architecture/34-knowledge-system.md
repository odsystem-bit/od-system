# Tracy Knowledge System

## Objectif

Le Knowledge System représente le savoir officiel de l'entreprise.

Contrairement à la mémoire, il ne contient pas des souvenirs.

Il contient les connaissances validées par l'entreprise.

Toutes les décisions importantes doivent s'appuyer sur le Knowledge System lorsqu'une connaissance pertinente existe.

---

# Les trois intelligences

Tracy distingue trois formes de connaissances.

## Memory

Informations spécifiques.

Exemple :

- le client préfère WhatsApp
- le magasin ouvre à 8h
- cette facture est en attente

---

## Knowledge

Connaissances officielles.

Exemple :

- procédure de remboursement
- politique commerciale
- règlement intérieur
- catalogue officiel
- politique RH

---

## Learning

Connaissances apprises avec le temps.

Exemple :

- les campagnes envoyées le mardi fonctionnent mieux
- les clients répondent davantage entre 18h et 20h
- cette stratégie augmente les ventes

# Cycle de vie

Une connaissance passe par plusieurs états.

BROUILLON

↓

EN_RELECTURE

↓

VALIDÉE

↓

PUBLIÉE

↓

ARCHIVÉE

Seules les connaissances validées peuvent être utilisées automatiquement.

# Versioning

Chaque document possède :

- version
- auteur
- date
- historique
- statut

Aucune version n'est perdue.

---

# Recherche

Le moteur peut rechercher :

- par mot-clé
- par catégorie
- par similarité sémantique
- par auteur
- par date
- par service
- par département

↓

# Objectif final
