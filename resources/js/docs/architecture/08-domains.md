# Domaines métier de Tracy

## Principe

Un domaine représente une responsabilité métier.

Chaque domaine est indépendant.

Les domaines communiquent uniquement via des contrats clairement définis.

- Employés

Un domaine ne dépend jamais directement d'un autre.

Il passe toujours par une interface publique.
