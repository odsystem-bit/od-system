# Tracy V1 - Fonctionnalités

## Objectif

La première version de Tracy doit être stable, simple et réellement utilisable par des entreprises.

La priorité n'est pas d'avoir le plus de fonctionnalités, mais d'automatiser efficacement la relation client et la gestion commerciale via WhatsApp.

---

# 1. Réponse aux clients

Statut : ✅ Priorité absolue

Tracy est capable de :

- Répondre automatiquement aux messages WhatsApp.
- Comprendre les questions des clients.
- Répondre avec les informations de l'entreprise.
- Répondre 24h/24.

---

# 2. Création de boutique Mantota

Statut : ✅

Le commerçant peut créer sa boutique directement depuis WhatsApp.

Tracy collecte les informations nécessaires puis crée automatiquement la boutique.

---

# 3. Gestion des produits

Statut : ✅

Le vendeur peut écrire :

- Ajoute ce produit.
- Modifie le prix.
- Supprime ce produit.
- Mets ce produit en promotion.

Tracy effectue directement les actions dans Mantota.

---

# 4. Recherche de produits

Statut : ✅

Le client peut demander :

- Je cherche un téléphone Samsung.
- Je cherche un ventilateur.
- Quel est votre produit le moins cher ?

Tracy interroge Mantota puis répond.

---

# 5. Gestion des commandes

Statut : ✅

Le vendeur peut demander :

- Mes commandes.
- Mes ventes du jour.
- Les commandes en attente.
- Les commandes livrées.

---

# 6. Mémoire de l'entreprise

Statut : 🚧

Tracy mémorise :

- horaires
- livraison
- politique de retour
- moyens de paiement
- informations importantes

Ces informations sont utilisées dans les conversations.

---

# 7. Scan automatique

Statut : 🚧

Tracy peut analyser un site web du commerçant afin d'importer automatiquement :

- produits
- prix
- images
- descriptions

Cette fonctionnalité est limitée aux sources compatibles.

---

# 8. Relance intelligente

Statut : 🚧

Tracy peut :

- détecter un panier abandonné
- relancer automatiquement un client
- envoyer un rappel après un délai configurable

---

# 9. Gestion en temps réel

Statut : ✅

Toutes les modifications peuvent être faites directement depuis WhatsApp.

Exemple :

"Augmente le prix du riz à 650 FCFA."

---

# 10. Tableau de bord

Statut : ✅

Le vendeur peut consulter :

- ventes
- commandes
- statistiques
- abonnements
- activité

---

# 11. Campagnes publicitaires

Statut : Désactivé

Le module est présent dans l'architecture.

Il sera activé dans une version ultérieure.

---
